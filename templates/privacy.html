Privacy & compliance.

PUBLIC PORTAL NOTICE · V11
Independent portal notice. This contractor/onboarding portal is not the official JSW Steel website.

Public application data

The public application is intentionally limited to basic candidate information: name, mobile number, qualification and selected role. Sensitive joining data is not requested through the public enquiry form.

Sensitive joining information

Fields such as Aadhaar, UAN/PF, ESIC and permanent-address details are handled later inside the authorized admin processing workflow when required for joining documentation.

Status lookup

The public status lookup uses the registered mobile number and returns only the candidate name, role and current workflow stage. It does not expose sensitive identity or statutory numbers.

Applicant enquiries

Applicants should not place Aadhaar, UAN, ESIC or other sensitive identifiers in the public grievance/contact message. Use the controlled joining process for those fields.

Project scope

This page describes the behavior of this portal implementation. Production deployment should additionally use organization-approved privacy terms, retention rules, encryption, access controls and infrastructure security policies.
